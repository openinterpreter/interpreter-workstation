# Welcome

Hello! Welcome to Interpreter. This is a sample workspace with a few example tasks.

## How to Use Interpreter

Press `{{MOD_KEY}}+L` to open the pinned agent sidebar, then click **New agent in sidebar**. Keeping the agent there lets you browse files, switch tabs, and compare documents while the conversation stays visible. Visit the [Use Cases.md](Notes/Use Cases.md) note for more ideas!

Use `@` to mention files without opening them. Press `{{MOD_KEY}}+K` to jump to any file. Press `{{MOD_KEY}}+N` to start a new agent conversation, or `{{MOD_KEY}}+T` to open a new tab.
