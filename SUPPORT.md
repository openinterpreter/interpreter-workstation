# Support

Use GitHub Discussions for usage and deployment questions and GitHub Issues for
reproducible defects. Search existing reports before opening a new one.

Security vulnerabilities must be reported privately as described in
`SECURITY.md`. Never post credentials, customer data, private documents, or
unredacted logs in a public issue.

The community project does not provide an SLA. Organizations that need a
supported deployment should define ownership for release qualification,
provider access, policy, endpoint management, and incident response.
