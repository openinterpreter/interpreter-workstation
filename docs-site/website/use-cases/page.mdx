# Use cases

Interpreter is a desktop agent for the work that lives between apps &mdash; reading source documents, filling forms, cleaning spreadsheets, drafting follow-ups, pulling research, updating records, building models, summarizing meetings. It opens the apps you already use and gets work done on your computer while you watch.

Pick the closest industry below to see real workflows people run today. None of these are demos &mdash; each is a workflow that an Interpreter agent can do end-to-end with your supervision.
