# Get started with Interpreter

Interpreter is a desktop agent for work that crosses apps, files, browser tabs, spreadsheets, PDFs, and documents. It opens the apps you already use, reads the files you point at, and gets work done on your computer while you watch (or step away).

<DocsContactButton />

## Who it is for

Knowledge workers in finance, legal, ops, research, and support who spend hours each week moving information between apps. You stay in control: Interpreter pauses for review before anything that submits, sends, deletes, or overwrites.

## What it can do

- Read and edit files in a workspace you choose &mdash; PDFs, DOCX, spreadsheets, plain text, images.
- Open and operate desktop apps the way you do: clicks, typing, menus, dialogs.
- Run web tasks across portals, dashboards, CRMs, and internal tools.
- Extract structured data from documents and write it into the format you need.
- Use your voice for hands-free instructions and follow-ups.
- Plug into your stack through MCP servers and built-in integrations.

## Where to start

If you have not installed it yet, start with [Install](/docs/desktop/install). If you have, jump to [Your first task](/docs/desktop/get-started) and pick one concrete workflow to try.

Want a feel for what it is good at before you start? Browse [use cases by industry](/docs/desktop/use-cases) &mdash; each industry page has real workflows with the apps they touch and the exact instruction to type.

## Keep control

Interpreter is most useful when you give it a narrow workspace, a clear output, and explicit review points before irreversible actions. [Approvals and safety](/docs/desktop/approvals) covers how to set that up so the agent moves fast without surprising you.
