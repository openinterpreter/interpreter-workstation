# Privacy

Interpreter works with the apps and files you choose to involve in a task. Treat those choices deliberately.

## Local files

Only point the agent at files and folders that are relevant to the workflow.

## Model providers

If you use a hosted model or your own API key, task content may be sent to that model provider to produce a response. Provider handling is governed by the provider you choose.

## Sensitive work

For sensitive files, prefer narrow workspaces, local models when appropriate, and explicit review before any external action.

## Do not share secrets

Do not put passwords, recovery codes, private keys, or unnecessary credentials into instructions.
