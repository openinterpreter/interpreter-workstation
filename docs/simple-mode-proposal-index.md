## Thematic reading order

1. **One durable agent** — a single long-lived conversation that remains
   responsive, delegates independent work, and receives messages from every
   surface without creating shadow chats.
2. **The interface is the workspace** — full-bleed executable React that the
   agent edits directly inside a safe filesystem project, with live visual
   feedback and no declarative-view substitute.
3. **One compact composer** — a minimal pill, attached activity tab, expanding
   conversation/settings/result drawer, voice/send/stop/steer/queue behavior,
   and the same logical object in the app and desktop overlay.
4. **Projects and files** — New/Open/Recent Interface, user-chosen standalone
   folders, multiple writable roots, canonical Workstation viewers/editors,
   ordinary selection, and intuitive drag/drop.
5. **Live collaboration** — hot source updates that preserve user state,
   last-known-good recovery, app-shipped dependencies, and direct interface
   messages back to the durable thread.
6. **Maintained design system** — exact Workstation surfaces where they exist,
   app-shipped Motion Primitives for everything else, minimal live-answer
   layouts, responsive grids, image/result presentation, and visible research
   or tool progress.
7. **Voice and channels** — GPT Live rather than dictation, WhatsApp replies on
   WhatsApp, optional enterprise policy controls, and source-aware routing.
8. **Startup and settings** — Simple as the default, Simple-specific
   onboarding, model visibility/management, workspace choice, and a reversible
   switch to Advanced.
9. **Deferred scope** — the separate addendum, iPhone, Tailscale, and
   remote/mobile serving are not part of the desktop implementation sprint.
